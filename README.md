# AI-Powered SQL Agent

🚀 This Text-to-SQL application empowers users to easily analyze their data by asking questions in plain English. An AI agent translates these questions into SQL queries, executes them, and returns the results. The generated SQL query is also displayed for transparency and learning.

## Prerequisites

To run this application, ensure you have the following:

- Python 3.7+
- A Google Gemini API key

## 🛠 Features

✅ **Flexible File Upload:** Upload your data as CSV or XLSX files to create an on-the-fly database.
✅ **Text-to-SQL Conversion:** Enter queries in plain English (e.g., "What are the average salaries by department?").
✅ **SQL Query Display:** See the actual SQL query generated by the AI before the result is shown.
✅ **AI-Powered:** Uses Google Gemini for natural language understanding and SQL generation.
✅ **Database Backend:** Utilizes SQLite for efficient, temporary database handling.
✅ **Interactive UI:** Built with Streamlit for a simple and user-friendly experience.

## 🚀 How to Use

1️⃣ **Clone this repository:**
   ```bash
   git clone https://github.com/Md-Inam/ai-sql-agent.git
   cd ai-sql-agent
   ```

2️⃣ **Set up your Google API Key:**
   It's recommended to set your Google API key as an environment variable named `GOOGLE_API_KEY`. You can do this by creating a `.env` file in the project root:
   ```
   GOOGLE_API_KEY="YOUR_API_KEY_HERE"
   ```
   Alternatively, you can enter it directly in the application's sidebar.

3️⃣ **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
   *(Ensure `requirements.txt` includes `streamlit`, `pandas`, `sqlalchemy`, `langchain-google-genai`, `langchain-community`, `python-dotenv`, and `openpyxl`)*

4️⃣ **Run the Streamlit app:**
   ```bash
   streamlit run app.py
   ```

5️⃣ **Interact:**
    Upload a CSV or Excel file using the sidebar, enter your question in the input field, view the generated SQL, and get your results!

## 🛠 Tech Stack

- Python
  - Streamlit (Web UI)

  - Langchain (AI agent framework)
